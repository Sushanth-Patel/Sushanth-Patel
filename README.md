# 🧠 `CURRENTLY IN THE LAB`

### Building a Language Model From Scratch

Instead of only calling an LLM API, I'm exploring what happens **under the hood**.

```text
                         RAW DATA
                            │
                            ▼
                    ┌───────────────┐
                    │  TOKENIZER    │
                    └───────┬───────┘
                            │
                            ▼
                     TOKEN IDs
                            │
                            ▼
                    ┌───────────────┐
                    │  EMBEDDINGS   │
                    └───────┬───────┘
                            │
                            ▼
              ┌─────────────────────────┐
              │       TRANSFORMER       │
              │                         │
              │   Multi-Head Attention  │
              │           ↓             │
              │   Feed Forward Network  │
              │           ↓             │
              │   Layer Normalization   │
              │           ↓             │
              │   Residual Connections  │
              └────────────┬────────────┘
                           │
                           ▼
                       TRAINING
                           │
                           ▼
                      CHECKPOINT
                           │
                           ▼
                       INFERENCE
                           │
                           ▼
                   GENERATED TEXT
```

**Stack:** `Python` `PyTorch` `Transformers` `NLP` `Intel XPU`

The goal isn't just to make a model generate text.

The goal is to understand **why it works**.
